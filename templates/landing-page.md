# Template, landing page

Audience: client, always. Stage: awareness to decision. Copy: `pages/landing-page.md`. Structure and rules: `reference/landing-page-structure.md`. Voice: `examples/landing-hero.md`.

Fill in this order and do not reorder blocks 2 to 5.

1. **Hero.** Category label "DONE-FOR-YOU LEAD GENERATION". One headline naming the transformation in the reader's words. Standfirst: what it is, plan, fill, convert, "any format, any size". The `icp-rule` "built for" line. Action: "Book a call".
2. **What your pipeline desperately needs.** Three needs framed deeper than symptoms. No product yet.
3. **What you're already doing right.** Four validations. Each one earns a pain in block 4.
4. **But you're still.** Five pains, each mirroring a validation. Two hero figures maximum, each with source and grade in a footnote.
5. **Crescendo.** No heading. The capitalised phrases stay capitalised.
6. **The solution.** "This isn't an events agency. This is a lead generation channel that happens to run in person."
7. **The big promise.** "Every lead has already met you in person." Checkmark list of capabilities, never performance. Action.
8. **How it works in 3 steps.** Plan, fill, convert. Each with a "stop, start" line, three bullets and a result. Status per `rules/service-status.md`.
9. **Beyond the 3 steps.** Measurement, IN BUILD, described as what we will report, never as reports delivered.
10. **vs the alternatives.** Comparison table, the cost table with every row the source has, the calculator, the line "Every conversion number in it is yours." Action.
11. **Transform closing.** Old way against new way.
12. **Founding client block.** Honest about being new. Terms from D13. Action.
13. **Footer.** "In-person, run as a lead generation channel."

## Fields to settle before publishing

## Guardrails

One audience, client. One call to action, "Book a call", identical wording every time. No FAQ, refusals block, navigation, second offer, format, size, city or country. Every figure footnoted with source and grade from `rules/evidence-ledger.md`. Every superlative through `rules/do-not-say.md`. No number of ours anywhere. Run `ops/QA-checklist.md` before shipping.
