# Template library

Skeletons for the channels this go-to-market actually runs, and only those. Fill the brackets, keep the guardrail line at the bottom, then run `ops/QA-checklist.md`. Every template names its audience. Guest templates keep their copy between the guest-copy markers so `scripts/lint_claims.py` can check it.

| Template | Audience | Use for | Status of the thing it produces |
|---|---|---|---|
| `landing-page.md` | Client | Editing or rebuilding the landing page in its 14-block anatomy | IN BUILD |
| `linkedin-post.md` | Client | Founder posts: teardown, category, arithmetic, wedge, trend, scope | READY |
| `prospect-approach.md` | Client | One researched approach to one prospect | READY at low volume |
| `discovery-call.md` | Client | The first call: qualify, diagnose, offer the coverage read | READY |
| `coverage-read.md` | Client | The one-page diagnostic on a named account list | READY |
| `scope-document.md` | Client | The one-page scope, half of it exclusions | BLOCKED, D1, D2, D4 |
| `composition-report.md` | Client | Targeted against invited, accepted and arrived, by account | IN BUILD |
| `observer-invitation.md` | Client | Inviting a prospect to observe the demonstration event | BLOCKED, D5 |
| `partnership-brief.md` | Partner | One page to an association or provider | IN BUILD, D15 |
| `guest-invitation.md` | Guest | The invitation, the reconfirmation, the note afterwards | BLOCKED, D5. Note afterwards partly D11 |
| `scorecard-email.md` | Client | The opt-in sequence after the coverage scorecard | BLOCKED, D1 |
| `decision-brief.md` | Internal | A one-page brief that puts an open decision to the founder | READY |

## Templates that do not exist, on purpose

There is no ad copy template, because paid advertising is excluded. There is no cold email sequence template, because sequences are excluded. There is no follow-up template for a guest who did not reply, because a non-reply is an answer. There is no newsletter template, because there is no list to send to and no channel built on posting frequency. A request for any of these is refused, with the rule named and the in-scope alternative offered.
