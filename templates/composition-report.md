# Template, composition report

Audience: client. Stage: value realisation. Status: IN BUILD as a format. Shown before purchase as the answer to the Manager's question "what do I report upward?" Never shown with invented sample data. A worked example must be clearly marked as a format example with no real or plausible-looking numbers.

## Sections

**[Client], composition report, [event or programme], [date]**

1. **The named list and the in-ICP definition**, as agreed in the scope.
2. **The funnel, by stage, with counts and dates.**

| Stage | Count | Date range | Note |
|---|---|---|---|
| Named accounts in scope | [n] | | |
| Accounts with an identified decision maker at the target title | [n] | | |
| Individuals approached | [n] | | One approach each |
| Replies of any kind, including declines | [n] | | Defined precisely. Not a positive reply rate |
| Accepted | [n] | | |
| Confirmed at reconfirmation | [n] | | |
| Arrived | [n] | | |
| Arrived and in-ICP | [n] | | Against the D4 promise |

3. **Coverage by account.** Which named accounts had a senior person present, which did not, and why where known. Accounts, not individuals, in anything shared beyond the client's core team.
4. **Title and seniority mix.** Against plan.
5. **Arrived against confirmed.** Against the Clutch Events category benchmark of 70%, labelled as a category benchmark.
6. **Post-event conversion.** In the form D11 settles. Qualified conversations from consenting guests, with the definition D9 names.
7. **What we learned about the list.** Coverage gaps, access gaps, titles that did not respond.
8. **Recommendation.** The next event, the next segment, or stop. Honest.

## Rules
- **Real numbers only.** This artifact exists to replace anecdote. Fabricating or rounding it up defeats the entire purpose, and it becomes the first proof point.
- Guest names are redacted for any external use, and never stored in this repository.
- Nothing said by a named guest is reported to the client without that guest's permission.

## Guardrails
Client audience. Every count traceable to the funnel table. No figure projected forward. Run `ops/QA-checklist.md` before sending.
