## Key journey insights

### Critical success factors

1. **The Room Readiness Read at stage 3 is the hinge of the whole funnel.** It is the only asset that gives value before payment, requires no track record, and produces a number about the buyer's own business. Every stage before it exists to earn it, and every stage after it reads from it.
2. **A valid invoice at stage 4.** Not persuasion, infrastructure. See blockers.
3. **The floor met at stage 5.** The first delivered room either creates the proof set or confirms the buyer's prior that nobody can fill these rooms. There is no neutral outcome.
4. **The reference at stage 6.** Every `{TBD}` in Phase 6 is fillable at this point and at no earlier point. Getting the first client to agree to be named is worth more than the second client's fee.

### Primary journey blockers

1. **No registered business name and no tax number, so no invoice a corporate accounts payable department will accept.** This is open decision 1 and it is first on the list because it is not a persuasion problem. Every earlier stage can run perfectly and the funnel still fails at stage 4, after the selling is done and the goodwill is spent. Register before the first proposal goes out, not before the first invoice.
2. **The competence reading at stage 4.** The User can kill the purchase silently by slow-walking the list and the date. Phase 5 sets the answer: sell capacity, never competence, and bring the User along rather than going over them.
3. **No reference at stage 3.** The buyer asks who else has done this, and the honest answer is nobody. The Room Readiness Read is the substitute, because a delivered artifact about their own list outperforms a case study about someone else's.
4. **Universe size at stage 5.** If the client's named list does not contain enough reachable executives in one city, the floor cannot be met and the engagement should not have been sold. The read at stage 3 exists to catch exactly this, and the discipline is to decline the engagement rather than accept it and hope.

### Acceleration opportunities

1. **Sell The List first.** It compresses stages 2 to 4 into one call at a small ticket, and it produces the artifact that makes The Room concrete. For ICP Level 1 it is the only sensible entry.
2. **The demonstration room, run at the founder's own cost.** It collapses stages 1 to 6 for every prospect who observes it and creates the first reference, the first guest cohort and the first auditable funnel table in one exercise. Phase 8 makes it a channel.
3. **Reconstruct the two commissioned rooms into an auditable table.** Open decision 3. It moves the proof set from empty to non-empty without delivering anything new, and it is the cheapest unblocking action available anywhere in this run.
4. **Settle the attendance floor.** Open decision 4. It arms drill 5, which is the strongest copy in Phase 6 and is currently a template.

## What the stages cost, honestly

The funnel has one person in every row. Stage 5 is a multi-week outreach cycle per engagement, and it is the same person running stages 1 to 4 for the next client. Two concurrent engagements is probably the ceiling before delivery quality or pipeline drops, and which one drops is not a choice that gets made deliberately. That ceiling is a Phase 9 input and a hiring trigger, not a detail.
