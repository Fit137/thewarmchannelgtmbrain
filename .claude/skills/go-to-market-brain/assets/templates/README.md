# Template library

Starting points, not final output. Instantiate only the templates matching the channel mix, then rewrite each one in the project's own vocabulary, archetypes, and guardrails. A template the business will never use is noise that dilutes retrieval, so delete it.

Every template ends with a guardrail line pointing at the rules files, because a template is where a hurried operator stops reading. Keep that line, and make it name the project's actual rules.

| Template | Use for |
|---|---|
| `landing-page.md` | Long-form pages, sales pages, product pages |
| `long-form-script.md` | YouTube, webinar, podcast, VSL, any spoken long form |
| `short-form-script.md` | Shorts, Reels, TikTok, clips |
| `social-post.md` | LinkedIn, X, threads, carousels |
| `newsletter.md` | Opt-in email sends |
| `seo-article.md` | Pillar guides, long-tail articles, comparison pages |
| `one-pager.md` | Sales leave-behinds, partner and internal briefs |
| `ad-copy.md` | Paid amplification, if paid is in the mix |
| `repurposing.md` | Turning one anchor asset into the full set |
