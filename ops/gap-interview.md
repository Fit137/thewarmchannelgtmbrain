# Gap interview, for the founder

The build skill asks for one batched round of questions on whatever the sources do not settle. This brain was built without that round, so the questions are here, each with the default the brain is running on. Answer in place, or tell an agent your answers, and each one is routed with the amendment procedure. An unanswered question keeps its default, and the default is never presented as a decision.

## How an answer becomes a rule

1. The answer is logged in `ops/signal-log.md` as STATUS, dated, quoted.
2. If it settles a D-number, the amendment procedure runs: ledger, master context, decision entry, copy, portable layer.
3. The default line above is replaced with the answer and the date.
