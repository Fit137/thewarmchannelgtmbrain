# Copy bank, approved language

Lines that have passed `rules/do-not-say.md`, so they are safe to reuse verbatim. Rewriting an approved line turns a checked claim into an unchecked one. Every line carries a status:

- **APPROVED**, verbatim from founder-directed source copy, cleared on 2026-10-07. Use as written.
- **HELD (Dn)**, approved wording, but publication waits on the named decision. Fine in internal drafts, never on a live surface.
- **PROPOSED**, written for this brain. Needs founder approval before use.
- **RETIRED**, superseded. Kept so the old form is recognisable and never reused.

When a decision changes a claim, grep this file for the old phrasing first. Stale approved copy is the most dangerous artifact in the brain, because it is reused without a second look.
